# Игровые иконки этапа 5Б

32 игровые иконки в стиле игры: объёмные, «игрушечные», тёплый свет, тёмный контур для читаемости.
Файлы PNG 512×512, прозрачный фон, отступ 6 % со всех сторон. Без белого ореола: подходят и для тёмных
панелей (navy), и для кремовых карточек. Как это выглядит — `contact_sheet.jpg`.

Служебные иконки (назад, закрыть, настройки, замок, календарь и т. п.) сюда не входят. Их берём из
набора Phosphor (MIT), владелец разрешил скачать.

## Откуда
- Higgsfield, модель Nano Banana Pro, 4K. Два листа 4×4, у каждого 2 варианта. Выбраны лучшие:
  лист A — job `df87a83d-8584-4d44-83d0-0bd8e10e467a`, лист B — job `d23b72d8-28ba-4919-be16-8b080488a600`.
- Потрачено 18 кредитов (одобрено владельцем до 250).
- Фон убран локально (`cutout.py`, цвет-в-прозрачность от белого), лист разрезан на иконки (`slice.py`).
  Сырые листы лежат вне репозитория: `~/Projects/unpaid-ceo-art/stage5b/raw/`.
- Повторить: `python3 cutout.py A2.png A.png && python3 cutout.py B1.png B.png && python3 slice.py A.png B.png out/`
  (нужны Pillow, numpy, scipy).

## Импорт в Unity
Скопировать в `game/Assets/UnpaidCeo/Art/` (папку выбрать по месту) и выставить: Texture Type — Sprite (2D and UI),
без mipmaps, Max Size 256 для мелких мест (HUD, чипы), 512 — для крупных (повышение уровня). Сжатие подобрать под
лимит веб-сборки 20 МБ. В UI Toolkit подключать как `background-image`.

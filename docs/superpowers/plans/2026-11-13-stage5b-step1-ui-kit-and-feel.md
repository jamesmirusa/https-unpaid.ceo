# Stage 5B · Step 1 — UI kit and game feel

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** The game looks and answers like a top mobile game: icons on every button, panels with volume, "thick"
buttons that sink when pressed, numbers that roll instead of jumping with a floating "+$51", bouncy popups, toasts,
soft tap sounds and (iPhone) a light haptic. Repainted: HUD, bottom dock, Week screen, rooms, week result.

**Spec:** `docs/superpowers/specs/2026-11-13-stage5b-living-city-top-look-design.md` («Вид топовых игр», delivery step 1).
Mockups: https://claude.ai/artifact/KocBu66cSL23THQC15GrN1 (Main, Week).

**Architecture:** No rule changes — Core untouched. A small UI layer in `Game/Ui/Kit/`:
`Icons` (white PNG icons tinted in USS: Phosphor MIT for service icons, Higgsfield sheets for game icons),
`Feel` (press feedback on every Button: class + sound + haptic within the same frame), `NumberRoll` (animated label
value with a final value known at once), `FloatingDelta` (the "+$51" that rises and fades), `Toasts` (top, 2 s),
`UiSound` (kinds → clips; procedural WAVs generated by `tools/audio/ui_sounds.py`) and `Haptics` (no-op on web, iOS
UIImpactFeedbackGenerator plugin). Styling stays in `Tokens.uss` + theme files; volume comes from per-side borders
("lip" under cards and buttons) and a 9-slice soft shadow sprite.

## Global constraints
- Every tap answers within the same frame (≤ 100 ms): class `feel--pressed` on pointer down, sound, haptic.
- Ordinary animation ≤ 0.4 s; nothing blocks input; reduced feel never hides a final value (tests read text at once).
- Strings only through `UI.tsv`; existing element names stay (tests and the onboarding refer to them).
- Web build ≤ 20 MB; icons ≤ 128 px (service) / 192 px (game).
- Old saves untouched (no state change in this step).

## Tasks
1. **Icons.** Rasterize the chosen Phosphor icons (`tools/art/ui/rasterize_icons.swift`) to
   `Resources/UI/Icons/*.png` + `LICENSE-phosphor.txt`; slice Higgsfield sheets (`tools/art/ui/slice_sheet.swift`)
   to `Resources/UI/GameIcons/*.png`. `Icons.Create(name, cls)`; test `Every_icon_the_ui_names_exists`.
2. **Feel.** `Feel.Attach(root)` registers PointerDown/Up on the panel and marks the pressed Button;
   `UiSound.Sink` + `Haptics.Sink` are swappable for tests. Tests: pressed class and a tap sound on pointer down; a
   disabled button gives no tap sound (it gives the soft "closed" one).
3. **Numbers.** `NumberRoll` on the HUD cash/energy; `FloatingDelta` near the cash when it changes after a week or a
   choice. Tests: final text right away via `Target`; a delta "+$51" appears with the positive class and is removed.
4. **Popups and toasts.** Popups and the week result open with `popup--in` (scale/opacity transition, ease-out-back
   0.25 s); `Toasts.Show(key)` top, 2 s. Tests: the class is set on open; a toast removes itself.
5. **Sounds and haptics.** `tools/audio/ui_sounds.py` (stdlib only) writes tap / pop / coin / success / closed /
   whoosh WAVs into `Audio/Sfx`; `AudioDirector.PlayUi` with the SFX volume; iOS plugin `Plugins/iOS/UnpaidHaptics.mm`.
6. **Repaint.** Tokens: lip shades, shadow sprite; thick primary button; HUD as in the mockup (coin pill, icon buttons,
   energy row with icon); dock with icons, raised active tab, badge counter; Week screen (mode tiles with icons in a
   4-column grid, focus chips, deed cards with an icon tile); rooms; week result (big money line, coins burst).
7. **Show.** Demo renders (`UiKitDemo`: city HUD, Week, room, week result; RU+EN), web build, size check, deploy, live
   hash check, screenshots to the owner; ledger + roadmap.

## Review focus
1. Tapping a closed card still says why (no silent tap) and plays the "closed" sound, not the tap.
2. Language switch while a delta floats — no stale text left behind.
3. Neon theme: every new colour has its night value.
4. Phone 1080×2340 and desktop: dock and HUD stay inside the column; touch targets ≥ 44 pt (≥ 132 px on the panel).

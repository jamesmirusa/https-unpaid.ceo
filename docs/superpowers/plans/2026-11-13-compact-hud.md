# План: компактная верхняя панель (AUTOPILOT §8)

Цель: на iPhone 375 pt верх в свёрнутом виде ≤ 12 % высоты, город виден от панели до нижних карточек.
Решение по дизайну принял владелец (AUTOPILOT §8) — здесь только порядок работ.

1. Тест `Game.Tests/CompactHudTests.cs` (красный): тонкая полоса, кольца нужд, меню, раскрытие/сворачивание (тап,
   свайп вверх, тап по городу, 5 с), память выбора, режим прогулки (1,5 с), тревога при сворачивании (кольцо +
   тост, неделя с платежом), нет полосы мест, «Места» — лист снизу, ≤ 12 % и город виден > 25 % высоты.
2. `Kit/NeedRing.cs` — кольцо прогресса Painter2D со значком внутри.
3. `Hud.uxml` → полоса (деньги, неделя, 4 кольца, меню) + линия цели + раскрывающаяся часть (полоски нужд с
   числами, календарь денег, цель главы, Журнал и Настройки).
4. `HudView.cs` — состояние, анимация, тревоги; `UiRoot` — подключение, `NotifyCityMotion`, без полосы мест,
   кнопки камеры в один ряд; `GameBootstrap` — движение камеры/героя → режим прогулки.
5. USS, строки EN/RU, старые тесты полосы мест → тест листа «Места»; дельты нужд летят над кольцом в свёрнутом виде.
6. Все тесты, ревью свежим ревьюером, веб, сборка iOS, скриншоты «было/стало» 375 и 430 pt, PR.

# Задание на автопилот: доделать веб (этап 5Б) и собрать iPhone (этап 6)

Это полное задание от владельца. Выполни его целиком, до конца, без остановок. Правила проекта — `CLAUDE.md`,
порядок и состояние — `docs/ROADMAP.md`. Этот файл главнее прошлых сообщений в чате, если они расходятся.

## 1. Режим работы
- Владелец не отвечает между шагами. Не задавай вопросов «продолжать?», «какой вариант?». Решай сам по спеке и
  записывай каждое решение строкой `Ruling: что решил — почему — чего стоит ошибка` в журнал плана.
- Спека 5Б и макеты утверждены владельцем 2026-11-13. Для этапа 6 сам напиши короткую спеку и план — владелец
  одобрил их заранее, ждать не нужно.
- Метод исполнения — executing-plans (реализуешь сам). На вопрос writing-plans о методе не жди ответа: выбирай его.
  В конце каждого шага — ревью всей ветки свежим ревьюером (субагент на самой сильной модели), затем одно
  исправление всех Critical/Important по TDD.
- Останавливайся только когда без владельца никак: вход Apple ID в Xcode, нажатие кнопки в Unity Editor, деньги.
  Тогда коротко напиши, что нажать и где, и **пока ждёшь — продолжай другую работу**, не простаивай.
- Если сессия оборвалась или контекст сжался: прогресс в `docs/ROADMAP.md` и журналах `.superpowers/sdd/`;
  `git log` — правда. Продолжай с первой незавершённой задачи, сделанное не переделывай.

## 2. Этап 5Б — шаги 1–5 (ветка `feat/stage5b-living-city`)
Спека: `docs/superpowers/specs/2026-11-13-stage5b-living-city-top-look-design.md`. Макеты: ссылка в спеке.
Для каждого шага по порядку:
1. План (`writing-plans`) → `docs/superpowers/plans/`.
2. Реализация по TDD; EditMode и PlayMode зелёные; серверные тесты зелёные, если трогал Core.
3. Проверка открытой карты: город → герой идёт → входит в бодегу → выходит. Ничего не сломано.
4. `tools/unity.sh build-web` → `tools/check-build-size.sh` (≤ 20 МБ) → `tools/deploy-web.sh` → убедись, что
   https://unpaid.ceo отдаёт новый `*.data.unityweb`.
5. Скриншоты 1080×1920 новых экранов (как `WeekScreenDemo`) в `game/TestResults/demo/`.
6. Коммит, push, строка «Сделано» в `docs/ROADMAP.md`.

После шага 5: проверка по доске из 6 осей (спека, раздел «Вид топовых игр»; навык `unity:craft-game-floors`,
visual-scorecard) — каждая ось ≥ 3, цель 4; что ниже 3 — исправить. Затем финальное ревью всей ветки,
исправления, PR в `design/unpaid-ceo-2-spec`, слияние, выкладка.

## 4. Сервер — без ключей
- Не используй `ugs login`. Выкладывай через Unity Editor на этом Mac: владелец вошёл в Editor своим аккаунтом
  Unity. Окно Deployment (пакет `com.unity.services.cloudcode` 2.10.4 уже в проекте). Модуль `server/cloudcode`
  подключи через Cloud Code Module Reference (`.ccmr`), конфиги из `server/ugs` — если пакеты их поддерживают.
- Если нужно нажать «Deploy» в Editor — один раз скажи владельцу, где кнопка, и продолжай работу.
- Убери пункт про `ugs login` из `docs/ROADMAP.md`; обнови `tools/server/deploy.sh` или опиши новый путь в README.

## 5. Этап 6 — iPhone (ветка `feat/stage6-iphone`, после слияния 5Б)
- Тот же проект Unity → сборка iOS → Xcode-проект → настоящее приложение. Не переписывать на Swift.
- Сделать: `tools/unity.sh build-ios` (batchmode → `game/Builds/iOS`), безопасные зоны (вырез, Dynamic Island),
  касания ≥ 44 pt, лёгкая вибрация на отклик (спека 5Б), 60 кадров/с на среднем iPhone и 30 на слабом, память
  ≤ 400 МБ, уровни качества. Вход «гость» сразу. Sign in with Apple и Google — по основной спеке, если это не требует
  платного аккаунта; иначе подготовь и отложи.
- Проверка: сборка для симулятора (Simulator SDK) → `xcodebuild` → запуск в симуляторе iOS → скриншоты
  `xcrun simctl io booted screenshot`. Тесты зелёные.
- Свой iPhone владельца: нужен его Apple ID в Xcode (бесплатная Personal Team). Попроси один раз, коротко, с точными
  шагами; пока ждёшь — делай остальное.
- TestFlight и App Store сейчас не делать (нужен Apple Developer $99/год) — подготовь чек-лист в
  `docs/superpowers/` на потом.
- Финальное ревью, исправления, PR, слияние.
